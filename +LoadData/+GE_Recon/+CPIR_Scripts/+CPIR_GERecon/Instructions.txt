###########################################################################
##***                How to add new MATLAB to fidall                  ***##
###########################################################################

1. Add functions to matlab_scpter_cchmc.m
    -We will compile this file so having the function in it, will include 
        it as a dependency
2. Create python access scripts for passing data to the functions
    -Confirm they have LF line endings for linux compatibility
3. Run compile_mascri.m on Linux with MATLAB and coder license
    -Needs to be on Linux since that is the platform GE is on
    -I installed MATLAB from UC onto WSL2 and run it there
4. Place mascriXXX_cchmc folder on scanner under ~/fidall/bin
5. Make sure the sonofrecon script that is used in the python access 
    scripts includes the mcr version you will be using in the setup_mcr
    function.
6. Make sure the scanner has the appropriate MATLAB runtime for the 
    compiled code and make sure the path to it exists in the sonofrecon
    script
    -If not, install it and add path to sonofrecon script (can use firefox 
	on scanner to download it
	-For v24.2, was installed to /export/home/signa/research/MATLAV/v242
	-Then confirmed with "python3 -c 'import sonofrecon_cchmc; sonofrecon_cchmc.setup_mcr()'
	-Then copied with "python3 -c 'import sonofrecon_cchmc; sonofrecon_cchmc.copy_mcr()'
7. Link rhrecons to python files as usual.
